# Kartu Ucapan Romantis

## Cara pasang di GitHub Pages
1. Ganti nama / isi pesan di `script.js` (bagian CONFIG) dan teks surat di `index.html`.
2. Taruh `musik.mp3`, `video.mp4` (dan opsional `poster.jpg`) di folder `assets/`.
3. Buat repository baru di GitHub, lalu upload SEMUA isi folder ini (termasuk `.nojekyll`).
4. Settings > Pages > Source: Deploy from a branch > Branch: main, folder: / (root) > Save.
5. Tunggu 1-2 menit, link: https://USERNAME.github.io/NAMA-REPO/

## Tips
- Upload lewat browser dibatasi 25 MB per file. Kompres video, atau upload lewat GitHub Desktop / git.
- Musik baru bunyi setelah tombol hati diketuk (aturan browser).
- Ketuk layar mana saja untuk hujan hati kecil.
